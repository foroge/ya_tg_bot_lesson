# Polite Echo Bot

Учебный репозиторий с несколькими Telegram-ботами, разработанными в рамках практических заданий по изучению библиотеки **python-telegram-bot**.

Каждая ветка содержит отдельного бота с собственной функциональностью и демонстрирует различные возможности разработки Telegram-ботов.

---

## Структура репозитория

```text
polite-echo-bot/
│
├── script/             # Бот с использованием ConversationHandler
├── date_and_time/      # Бот для работы с датой и временем
├── dice_and_timer/     # Бот с виртуальными кубиками и таймером
└── set_timer/          # Отдельная реализация Telegram-таймера
└── polite-echo-bot/    # Бот, который повторяет сообщения
```

---

## Реализованные боты

### Polite-echo-bot
Функциональность:
- возврат сообщения отправителя

### Script

Демонстрация работы с **ConversationHandler**.

Функциональность:

- пошаговый диалог с пользователем;
- сохранение пользовательских данных между этапами диалога;
- возможность пропустить отдельный вопрос;
- завершение диалога по команде `/stop`.

---

### Date and Time

Бот для работы с текущими датой и временем.

Функциональность:

- получение текущей даты;
- получение текущего времени;
- работа с соответствующими командами Telegram.

---

### Dice and Timer

Бот с игровыми и вспомогательными функциями.

Функциональность:

- бросок кубиков:
  - d6;
  - 2×d6;
  - d20;
- установка таймера:
  - 30 секунд;
  - 1 минута;
  - 5 минут;
- отмена активного таймера;
- использование пользовательской клавиатуры Telegram.

---

### Set Timer

Отдельная реализация Telegram-бота с функцией таймера.

Функциональность:

- создание таймеров;
- уведомление пользователя после окончания отсчета;
- управление активными таймерами.

---

## Используемые технологии

- Python
- python-telegram-bot
- AsyncIO
- Telegram Bot API
- Logging
